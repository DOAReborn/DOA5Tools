GuideGuide

Features, install, settings and FAQ.

Fonctions, installation, réglages et FAQ.

Features

Fonctions

Lobby

Salons

  • Adds the missing Lobby entry to the Online menu, with pretty much every feature available.
  • Working invitations. Press F7 in a lobby to copy your room link to the clipboard.
  • Text chat: Enter (keyboard) or Start (controller) in a lobby. Everyone in the lobby needs DOA5Tools 1.2 or later.
  • CONNECTION setting when creating a lobby: players with a worse connection can’t join.
  • The host’s Kick button works, and kicked players can’t come back to that lobby.
  • Ajoute l’entrée Salon manquante au menu En ligne, avec presque toutes ses fonctions.
  • Invitations fonctionnelles. F7 dans un salon copie le lien du salon dans le presse-papiers.
  • Chat texte : Entrée (clavier) ou Start (manette) dans un salon. Tout le salon doit avoir DOA5Tools 1.2 ou plus récent.
  • Réglage CONNECTION à la création d’un salon : les joueurs moins bien connectés ne peuvent pas entrer.
  • Le bouton Expulser de l’hôte fonctionne, et un joueur expulsé ne peut pas revenir dans ce salon.

Rematch

  • With only two players queuing in a lobby (both with DOA5Tools 1.3+), a Rematch menu shows up at the end of a fight so you can play again right away.
  • If a player leaves the menu or a third player joins the queue, the room goes back to normal.
  • Spectators can watch rematches with the lobby’s built-in spectator mode (do not queue).
  • Quand seuls deux joueurs sont dans la file d’un salon (tous deux avec DOA5Tools 1.3+), un menu Rematch s’affiche en fin de combat pour rejouer tout de suite.
  • Si un joueur quitte le menu ou qu’un troisième rejoint la file, le salon reprend son fonctionnement normal.
  • Les spectateurs peuvent suivre les rematchs avec le mode spectateur du salon (sans entrer dans la file).

Console stages

Stages console

  • Attack on Titan: no more frozen round after the Titan’s Power Blow; wall and K.O. like on PS4 (online: everyone needs DOA5Tools 1.5).
  • PS4 restart points from round 2 on the console stages.
  • Console stages in Arcade, Time Attack and Survival.
  • Attack on Titan : plus de round figé après le Power Blow du Titan ; mur et K.O. comme sur PS4 (en ligne : tout le monde doit avoir DOA5Tools 1.5).
  • Points de reprise PS4 à partir du round 2 sur les stages console.
  • Stages console en Arcade, Time Attack et Survival.

Miscellaneous

Divers

  • EXTRA OPTIONS menu in the main menu: turn DOA5Tools, rollback and DOA5Extra features on or off.
  • Shows your real connection type to others: [n] wired, <n> Wi-Fi.
  • Borderless fullscreen (F11 cycles between modes).
  • Skips the startup logos and intro.
  • Runs at your desktop resolution, ultrawide and other screens included (21:9, 32:9, 16:10…).
  • Experimental 120/144 fps in fights (off by default, F3).
  • Replay list in rows (names, characters, stage, date), filters by character (L1) and player (R1), archives (Square).
  • Skips character intros and the victory pose (Cross / Start).
  • Extra stage slots: the PS4 stages installed with DOA5Installer (online and in Random when everyone has them).
  • Menu d’options des mods dans le menu principal : activer ou couper les fonctions de DOA5Tools, du rollback et de DOA5Extra.
  • Affiche aux autres votre vrai type de connexion : [n] filaire, <n> Wi-Fi.
  • Plein écran fenêtré (F11 passe d’un mode à l’autre).
  • Passe les logos et l’intro au démarrage.
  • Tourne à la résolution du bureau, écrans ultrawide et autres formats compris (21:9, 32:9, 16:10…).
  • 120/144 fps expérimental en combat (coupé par défaut, F3).
  • Liste des replays en lignes (pseudos, persos, stage, date), filtres par perso (L1) et par joueur (R1), archives (Carré).
  • Passe l’intro des persos et la pose de victoire (Croix / Start).
  • Emplacements de stages en plus : les stages PS4 installés par DOA5Installer (en ligne et au Random si tout le monde les a).

Install

Installation

  1. A clean Steam install of the game is recommended.
  2. Extract DOA5Installer next to game.exe.
  3. Run DOA5Installer.exe, click Add zips (DOA5Tools.zip and the other DOAReborn zips), then Install.
  4. Launch the game.
  1. Une installation Steam propre du jeu est conseillée.
  2. Extraire DOA5Installer à côté de game.exe.
  3. Lancer DOA5Installer.exe, cliquer sur Add zips (DOA5Tools.zip et les autres zips DOAReborn), puis Install.
  4. Lancer le jeu.

Manual install: extract the zip next to game.exe. Fully compatible with AutoLink. To uninstall, use DOA5Installer.

Installation manuelle : extraire le zip à côté de game.exe. Entièrement compatible avec AutoLink. Pour désinstaller, passer par DOA5Installer.

Linux / Steam Deck (Proton)

In Steam: right-click the game → Properties → Launch options, and paste:

Dans Steam : clic droit sur le jeu → Propriétés → Options de lancement, puis coller :

WINEDLLOVERRIDES="dinput8=n,b" %command%

Without it, Proton uses its own dinput8.dll and the plugin silently does not load. With ReShade or another d3d9.dll mod: WINEDLLOVERRIDES="dinput8,d3d9=n,b" %command%

Sans cela, Proton utilise son propre dinput8.dll et le plugin ne se charge pas, sans message. Avec ReShade ou un autre mod d3d9.dll : WINEDLLOVERRIDES="dinput8,d3d9=n,b" %command%

Settings

Réglages

Turn features on or off in the EXTRA OPTIONS menu (main menu), or set them to 0 in [DOA5Tools] of DOA5Tools.ini:

Activer ou désactiver les fonctions dans le menu EXTRA OPTIONS (menu principal), ou les mettre à 0 dans [DOA5Tools] de DOA5Tools.ini :

[DOA5Tools]
Lobby=1
JoinFix=1
Rematch=1
WiFiWired=1
Borderless=1
HighFps=0
Skip=1
Ultrawide=1
ReplayMenu=1
LobbyChat=1
StageSlots=1
IntroOutroSkip=1
LobbyName=1
  • F7 in a lobby copies your room link.
  • [Rematch] Tirage: random characters/stage on rematch, 1 = new draw, 0 = same as last fight.
  • [Borderless] Mode: 2 borderless, 1 window, 0 game setting. F11 cycles the modes.
  • [Ultrawide] Width/Height: 0 = your desktop resolution.
  • [ReplayMenu] Recycle: 1 = deleted replays go to a REPLY_CORBEILLE folder, 0 = erased for good.
  • [StageSlots] Extra: 1 = PS4 stages shown (online: only if everyone has them).
  • F7 dans un salon copie le lien du salon.
  • [Rematch] Tirage : personnages/stage aléatoires au rematch, 1 = nouveau tirage, 0 = comme au combat précédent.
  • [Borderless] Mode : 2 plein écran fenêtré, 1 fenêtre, 0 réglage du jeu. F11 fait défiler les modes.
  • [Ultrawide] Width/Height : 0 = résolution du bureau.
  • [ReplayMenu] Recycle : 1 = les replays supprimés vont dans un dossier REPLY_CORBEILLE, 0 = effacés pour de bon.
  • [StageSlots] Extra : 1 = stages PS4 affichés (en ligne : seulement si tout le monde les a).

FAQ

The Lobby entry does not appear.

L’entrée Salon n’apparaît pas.

Check that dinput8.dll and DOA5Tools.asi are next to game.exe. On Linux, check the launch option above.

Vérifier que dinput8.dll et DOA5Tools.asi sont à côté de game.exe. Sous Linux, vérifier l’option de lancement ci-dessus.

Do both players need the plugin?

Les deux joueurs doivent-ils avoir le plugin ?

For Rematch, both players in the queue need DOA5Tools 1.3+. For chat and PS4 stages, everyone in the lobby.

Pour le rematch, les deux joueurs de la file doivent avoir DOA5Tools 1.3+. Pour le chat et les stages PS4, tout le salon.

Does it modify game files?

Est-ce que ça modifie les fichiers du jeu ?

No. Everything happens in memory while the game runs. Deleting the files restores the original game.

Non. Tout se passe en mémoire pendant que le jeu tourne. Supprimer les fichiers rend le jeu d’origine.
