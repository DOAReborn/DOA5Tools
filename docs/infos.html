Features, install and FAQ.

Fonctions, installation et FAQ.

Features

Fonctions

Lobby

Salons

  • Adds the missing Lobby entry to the Online menu, with pretty much every feature available.
  • Working invitations.
  • Text chat in lobbies: Enter (keyboard) or Start (controller).
  • Lobby names in the lobby list, and your own ROOM name.
  • CONNECTION setting when creating a lobby.
  • The host’s Kick button works, and kicked players can’t come back to that lobby.
  • Ajoute l’entrée Salon manquante au menu En ligne, avec presque toutes ses fonctions.
  • Invitations fonctionnelles.
  • Chat texte dans les salons : Entrée (clavier) ou Start (manette).
  • Noms des salons dans la liste, et votre propre nom ROOM.
  • Réglage CONNECTION à la création d’un salon.
  • Le bouton Expulser de l’hôte fonctionne, et un joueur expulsé ne peut pas revenir dans ce salon.

Rematch

  • With only two players queuing in a lobby, a Rematch menu shows up at the end of a fight so you can play again right away.
  • If a player leaves the menu or a third player joins the queue, the room goes back to normal.
  • Spectators can watch rematches with the lobby’s built-in spectator mode (do not queue).
  • Quand seuls deux joueurs sont dans la file d’un salon, un menu Rematch s’affiche en fin de combat pour rejouer tout de suite.
  • Si un joueur quitte le menu ou qu’un troisième rejoint la file, le salon reprend son fonctionnement normal.
  • Les spectateurs peuvent suivre les rematchs avec le mode spectateur du salon (sans entrer dans la file).

Miscellaneous

Divers

  • EXTRA OPTIONS menu in the main menu: turn DOA5Tools, rollback and DOA5Extra features on or off.
  • Shows your real connection type to others: [n] wired, <n> Wi-Fi.
  • Borderless fullscreen.
  • Skips the startup logos and intro.
  • Runs at your desktop resolution, ultrawide included.
  • 120/144 fps in fights (off by default, experimental).
  • Replay list in rows, with filters by character and player. Archive replays to get past the limit.
  • Skips character intros and the victory pose.
  • Extra stage slots for the stages installed with DOA5Installer.
  • Console stages in Arcade, Time Attack and Survival.
  • Menu EXTRA OPTIONS dans le menu principal : activer ou couper les fonctions de DOA5Tools, du rollback et de DOA5Extra.
  • Affiche aux autres votre vrai type de connexion : [n] filaire, <n> Wi-Fi.
  • Plein écran fenêtré.
  • Passe les logos et l’intro au démarrage.
  • Tourne à la résolution du bureau, ultrawide compris.
  • 120/144 fps en combat (coupé par défaut, expérimental).
  • Liste des replays en lignes, avec filtres par perso et par joueur. Archivez vos replays pour dépasser la limite.
  • Passe l’intro des persos et la pose de victoire.
  • Emplacements de stages en plus pour les stages installés par DOA5Installer.
  • Stages console en Arcade, Time Attack et Survival.

Install

Installation

  1. A clean Steam install of the game is recommended.
  2. Extract DOA5Installer next to game.exe.
  3. Run DOA5Installer.exe, click Add zips (DOA5Tools.zip and the other DOAReborn zips), then Install.
  4. Launch the game.
  1. Une installation Steam propre du jeu est conseillée.
  2. Extraire DOA5Installer à côté de game.exe.
  3. Lancer DOA5Installer.exe, cliquer sur Add zips (DOA5Tools.zip et les autres zips DOAReborn), puis Install.
  4. Lancer le jeu.

Manual install: extract the zip next to game.exe. Fully compatible with AutoLink. To uninstall, use DOA5Installer.

Installation manuelle : extraire le zip à côté de game.exe. Entièrement compatible avec AutoLink. Pour désinstaller, passer par DOA5Installer.

Linux / Steam Deck (Proton)

Install with python3 doa5installer.py install <zip>..., then in Steam: right-click the game → Properties → Launch options, and paste:

Installer avec python3 doa5installer.py install <zip>..., puis dans Steam : clic droit sur le jeu → Propriétés → Options de lancement, et coller :

WINEDLLOVERRIDES="dinput8=n,b" %command%

Settings

Réglages

Turn features on or off in the EXTRA OPTIONS menu (main menu), or set them to 0 in DOA5Tools.ini.

Activer ou couper les fonctions dans le menu EXTRA OPTIONS (menu principal), ou les mettre à 0 dans DOA5Tools.ini.

FAQ

The Lobby entry does not appear.

L’entrée Salon n’apparaît pas.

Install again with DOA5Installer. On Linux, check the launch option above.

Réinstaller avec DOA5Installer. Sous Linux, vérifier l’option de lancement ci-dessus.

Do both players need the plugin?

Les deux joueurs doivent-ils avoir le plugin ?

For Rematch, both players in the queue. For chat and extra stages, everyone in the lobby.

Pour le rematch, les deux joueurs de la file. Pour le chat et les stages en plus, tout le salon.

Does it modify game files?

Est-ce que ça modifie les fichiers du jeu ?

No. Everything happens in memory while the game runs.

Non. Tout se passe en mémoire pendant que le jeu tourne.
